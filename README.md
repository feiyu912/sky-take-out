# Sky Take-Out 外卖系统

## 项目介绍
Sky Take-Out是一个基于Spring Boot开发的外卖点餐系统，包含商家管理后台和用户点餐前台。系统提供了菜品管理、套餐管理、订单管理、用户管理等核心功能，支持微信支付、WebSocket实时通知等特性。

## 技术栈

### 后端技术
- **Spring Boot 3.3.7** - 应用框架
- **MyBatis 3.0.3** - ORM框架
- **MySQL 8.0.30** - 数据库
- **Redis** - 缓存
- **JWT** - 身份认证
- **WebSocket** - 实时通信
- **阿里云OSS** - 文件存储
- **Knife4j 3.0.3** - API文档
- **微信支付** - 在线支付
- **Lombok 1.18.32** - 代码简化
- **Druid 1.2.1** - 数据库连接池
- **PageHelper 1.4.7** - 分页插件
- **Fastjson 1.2.76** - JSON处理

### 开发工具
- **Maven** - 项目管理和构建
- **IntelliJ IDEA** - IDE

## 核心功能模块

### 1. 管理端功能
- **员工管理** - 员工信息的增删改查、状态管理
- **分类管理** - 菜品分类、套餐分类的管理
- **菜品管理** - 菜品信息的管理，包括口味配置
- **套餐管理** - 套餐的管理，包括菜品关联
- **订单管理** - 订单的查询、状态更新、拒单等操作
- **数据统计** - 销售数据统计、经营分析
- **工作台** - 订单概览、销量统计等

### 2. 用户端功能
- **用户登录** - 微信授权登录
- **地址管理** - 收货地址的管理
- **菜单浏览** - 菜品、套餐的查看
- **购物车** - 菜品的添加、删除、修改数量
- **订单管理** - 下单、支付、查询订单、取消订单

## 系统特点

1. **分层架构** - 清晰的MVC分层架构设计
2. **安全认证** - 基于JWT的身份认证机制
3. **缓存优化** - Redis缓存热点数据，提升性能
4. **实时通信** - WebSocket实现订单状态实时推送
5. **文件存储** - 阿里云OSS存储图片等静态资源
6. **在线支付** - 集成微信支付功能

## 快速开始

### 环境要求
- JDK 17+
- Maven 3.6+
- MySQL 8.0+
- Redis 5.0+
- 阿里云OSS账号

### 安装步骤

1. **克隆项目**
   ```bash
   git clone <项目地址>
   cd sky-take-out
   ```

2. **配置数据库**
   - 创建MySQL数据库
   - 导入数据库脚本（需单独准备）
   - 修改`application.properties`中的数据库连接信息

3. **配置阿里云OSS**
   - 登录阿里云OSS管理控制台
   - 创建存储桶，设置ACL为"公共读"
   - 修改`application.properties`中的OSS配置信息

4. **配置微信支付**
   - 获取微信支付相关配置
   - 修改配置文件中的微信支付参数

5. **构建项目**
   ```bash
   mvn clean package
   ```

6. **运行项目**
   ```bash
   java -jar sky-server/target/sky-server-1.0-SNAPSHOT.jar
   ```

### 访问地址
- 管理端：`http://localhost:8080/admin/`
- 用户端：`http://localhost:8080/`
- API文档：`http://localhost:8080/doc.html`

## 注意事项

1. **图片显示问题**
   - 确保阿里云OSS存储桶ACL设置为"公共读"
   - 登录阿里云OSS管理控制台 → 找到对应存储桶 → 进入"权限控制"页面 → 设置ACL为"公共读"

2. **JWT密钥配置**
   - 生产环境中请使用强密钥并定期更换
   - 在`application.properties`中配置JWT相关参数

3. **Redis连接配置**
   - 确保Redis服务已启动
   - 修改配置文件中的Redis连接信息
